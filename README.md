# Anime by Adi 💀 - Full Stack React & Express Application

## ⚠️ Important Note About Running the Project
This is a **Full-Stack React + TypeScript + Vite + Express** application with Firebase Authentication, Firestore database integration, and backend API routes.

You **cannot** run this app by simply double-clicking `index.html`. It requires Node.js and a local development server.

---

## 🚀 How to Run Locally (Step by Step)

1. **Install Node.js** (v18 or higher recommended) from [nodejs.org](https://nodejs.org/).
2. Open your terminal / command prompt in this project folder.
3. Install all dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and go to:
   `http://localhost:3000`

---

## 🛠️ Available Scripts
- `npm run dev` - Starts the backend Express server & Vite dev middleware.
- `npm run build` - Builds the React frontend for production into `dist/`.
- `npm run start` - Runs the production server (`node server.ts`).
- `npm run lint` - Checks TypeScript types and code linting.
